# AIK-VdGeneration: Web Studio Client (`apps/web`)

## Overview
Web application built with **Next.js 14+ (App Router)** and **Tailwind CSS**. It serves as the primary visual studio for users to create, preview, edit, and export AI slide videos.

## Features (Planned in Phase 2)
1. **Prompt & Script Studio:**
   - Topic input box with quick prompt templates (Educational, Marketing, Pitch Deck, Tech Explainer).
   - Language selector (Vietnamese / English).
   - Voice preview player (sample audio of selected narrator voices).
2. **Interactive Slide Reviewer:**
   - Review AI-generated slides before rendering video.
   - Edit slide headings, bullet points, and speaker notes directly.
3. **Live Render Tracker:**
   - Realtime WebSocket progress bar with animated stages.
   - Built-in video player with 1080p download & shareable links.

## Quickstart (Once configured in Phase 2)
```bash
npm install
npm run dev
```
