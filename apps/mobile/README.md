# AIK-VdGeneration: Mobile Client (`apps/mobile`)

## Overview
Cross-platform mobile application built with **Flutter** (or React Native) targeting iOS and Android.

## Features (Planned in Phase 4)
- Voice-to-Prompt: Record your voice idea and generate a presentation video on the go.
- Aspect ratio selection tailored for mobile viewing: `9:16` vertical video for TikTok/Reels/Shorts, or `16:9` widescreen.
- Push notifications when video rendering completes.
- Native device video sharing.
